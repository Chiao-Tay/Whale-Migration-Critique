# The Humpback Highway

A data story about the whales that migrate along Australia's coasts. FIT3179 Data Visualisation 2.

- `index.html`: the web page
- `specs/`: one Vega-Lite specification per chart (`.vg.json`)
- `data/`: chart-ready data files, plus `DATA_NOTES.md` describing sources and cleaning rules
- `css/style.css`: page styles
